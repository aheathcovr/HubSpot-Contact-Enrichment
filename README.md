# HubSpot Contact Enrichment

This repository contains tools and scripts for enriching HubSpot contact data.

## Description
A project for enhancing HubSpot contact information with additional data points and enrichment capabilities.

- `State Association Contact Enrichment/`: the enrichment service (Cloud Run).
- `hubspot-app/`: a HubSpot app that lets a rep ask for enrichment from a company record. Not uploaded to HubSpot yet; see its README.
